首次使用

  1. 自行部署兼容的 wrapper-v2（API 0.0.2），仅向本机或可信内网开放。
  2. 在插件配置的 Apple Music 解析器中启用可选后端，填写 wrapper 地址，保存并重载插件。
  3. 使用独立 Python 环境安装 gamdl 3.9.1，填写该环境的 Python 路径；FFmpeg 和 FFprobe 放入 PATH。
  4. 在本页登录并核验订阅，验证单曲后再开启「返回单曲音频」。

日常只需在此刷新或重新登录。wrapper 的持久卷可保存 Apple 会话，但过期仍需重新认证。清除内存会话不会删除磁盘缓存，不是完整注销。
